# 🎉 TodoMaster – Your Ultimate Task Manager

Welcome to **TodoMaster**, a sleek and powerful task management app built with **React**, **Supabase**, and **Tailwind CSS**. Whether you're managing personal tasks or projects, TodoMaster offers a beautiful and responsive interface across all devices.

---

## 🚀 Features

| Feature               | Description                                                                 |
|-----------------------|-----------------------------------------------------------------------------|
| ✨ HTML/CSS Rendering  | Add and render tasks with custom HTML/CSS for a personalized experience.    |
| 📱💻 Responsive Design | Adapts seamlessly to all screen sizes—from mobile to desktop.                |
| ✍ Easy Editing        | Large, resizable input fields for editing complex tasks with ease.          |
| 🔍 Smart Filtering     | View tasks by **All**, **Completed**, or **Pending** status.                 |
| ⏱ Real-Time Sync      | Tasks update instantly with Supabase backend integration.                   |
| 🎨 Stylish UI         | Gradient backgrounds, shadows, and modern hover effects.                    |
| 🌙 Dark Mode          | Toggle dark mode for a comfortable viewing experience.                      |

---

## ⚙️ Getting Started

### ✅ Prerequisites
- [Node.js](https://nodejs.org/) (v14 or higher)
- `npm` or `yarn`
- Supabase account for backend setup

### 📦 Installation

Clone the repo:
```bash
git clone https://github.com/Ridham-Savaliya/to-do-webapp.git
cd todomaster

Install dependencies:

npm install
# or
yarn install

🔧 Supabase Configuration
Create a Supabase project and add your credentials to a .env file:

VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-anon-key

Start the development server:

npm run dev
# or
yarn dev

💡 Usage
➕ Adding a Todo
Enter a task or custom HTML/CSS (e.g., <p style="color:red;">Task</p>) in the input.

Click Add Todo to save it.

📝 Editing a Todo
Click the edit (📝) icon to update a task.

Modify the content and click 💾 Save or ❌ Cancel.

📂 Filtering Tasks
Use filters: All, Completed, Pending.

Completed tasks are hidden from "All" and "Pending" views.

✅ Marking as Completed
Click the ✔ icon to toggle completion.

Completed tasks have a sleek line-through style.
